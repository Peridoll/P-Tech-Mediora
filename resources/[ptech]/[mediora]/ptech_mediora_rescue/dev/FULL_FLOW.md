# 保留中の搬送プロトタイプ

以下は通常搬送の設計・実装メモです。現在のmanifestでは起動しません。

# P-Tech Mediora Rescue

勤務中の警察官がダウンした際、NPCヘリで本院へ搬送するリソースです。死亡・瀕死状態とHPは変更せず、到着後の蘇生・治療はEMSが行います。FiveM実機での結合試験は未完了です。

## 使用方法

1. 対象職で勤務中にダウンすると、サーバーが待機時間を計測します。標準設定は8分です。
2. 待機終了後、Rキーを3秒長押しして要請します。
3. 頭上の屋根を探索し、その上の救助機へ回収します。現在の回収演出は1秒待機後の座席配置です。
4. ヘリが本院ヘリポートへ飛行し、病院付近に到達した場合だけ入口へ患者を配置します。
5. 同じルーティングバケット内の勤務中EMSに、搬送開始と到着を各1回通知します。

搭乗をサーバーが確認する前に失敗した場合は再要請できます。搭乗確認後は、その死亡セッションでの再使用を禁止します。蘇生すると次のダウンで待機時間が再設定されます。

搬送失敗時は搭乗者を回収前の位置へ戻します。サーバーでの機体削除時にも、同じキャラクター・ped・バケットの搭乗者を確認して復帰させます。外部処理で移動した患者や、キャラクター・ped・バケットが切り替わったプレイヤーには復帰移動を適用しません。

## 導入

必須リソースは `ox_lib`、`qbx_core`、`wasabi_ambulance` です。OneSyncを有効にしてください。Coreの共通アクションパネルを使用する場合は `ptech_mediora_core` も起動します。Coreがない場合は画面へのテキスト表示に切り替わります。Marineの起動は不要です。

```cfg
ensure ox_lib
ensure qbx_core
ensure wasabi_ambulance
ensure ptech_mediora_core
ensure ptech_mediora_rescue
```

`config.lua` の `Config.Hospital.Helipad` と `Config.Hospital.Entrance` はPillbox用の仮座標です。導入先MLOのヘリポート・入口へ合わせてください。職業名、待機時間、操作キー、ヘリのモデルと飛行設定もこのファイルで変更できます。

操作キーは `Config.Key` が初期値です。FiveMの「設定 → キーの割り当て → FiveM」にある **Mediora Rescue：緊急離脱（長押し）** から変更できます。画面にも割り当て済みのキーを表示します。死亡中のGTA標準リロード操作ではなく、Rescue専用のキー保持状態を読み取ります。長押し中は進捗％を表示し、3秒完了後は「救助要請を送信しています」に切り替わります。

満タン後の応答待ちは秒数付きで表示します。標準では15秒で応答待ちを終了し、同じ要請の未搭乗機体を取り消します。サーバーから拒否理由・生成失敗理由が返った場合は、赤いパネルに4秒間表示します。再試行するときは一度キーを離してから長押ししてください。

開始しない場合はF8とサーバーログの `[ptech_mediora_rescue]` を確認します。順番は「長押し完了・要請送信」（クライアント）→「要請受理」（サーバー）→「機体準備完了」（サーバー）→「要請応答」（クライアント）です。最後に出ている段階と「要請失敗」の理由で、通信・資格確認・生成・配信を切り分けます。

受理後の職業・勤務・死亡状態はサーバーが継続確認します。クライアント側Qbox情報の同期遅延だけでは要請を中断しません。サーバー側で取り消した場合は「ヘリ消失」「操縦士消失」「勤務状態終了」「死亡・瀕死状態終了」などの理由を赤いパネルに4秒間表示し、F8にも「サーバー取消受信」「搬送中断」を記録します。

## 検証用の時短コマンド

- `/rescueskip`：自分の現在の待機時間をスキップ。
- `/rescueskip 12`：プレイヤーID 12 の現在の待機時間をスキップ。
- サーバーコンソールでは `rescueskip 12` のようにIDを指定。

ゲーム内での実行にはACE権限 `command.rescueskip` が必要です。管理者グループへ付与する場合は `server.cfg` に次を追加します。

```cfg
add_ace group.admin command.rescueskip allow
```

Coreのチャット候補・`/mediorahelp rescueskip` にも登録しています。使用権限があり、Rescueが起動している場合に表示します。Coreのヘルプ設定を更新した場合はCoreも再起動してください。権限を変更した直後は `/mediorahelp` を実行すると候補も再取得します。

対象は勤務中の許可職で、死亡または瀕死状態のプレイヤーです。スキップ後は通常どおりRを3秒長押しして要請します。表示は次の状態同期（標準では約1秒以内）で更新します。要請中・搬送中・使用済みの状態は解除しません。次のダウンでは通常の8分待機に戻ります。

## 現在の制限

- ロープの描画・巻き上げアニメーションは未実装です。
- ヘリ・パイロットはサーバー生成のネットワークエンティティです。標準設定では最初の20秒は他のプレイヤーから隠し、本人には半透明で表示します。公開時の表示とstream-in直後の一瞬の露出は実機確認が必要です。
- 機体・パイロットの衝突を無効にしています。NPCの飛行・着陸、Wasabiによる死亡アニメーション・座席制御との併用は実機調整が必要です。
- 屋根探索は上方180mまでです。高層建築、地下、MLOによっては回収高度の調整が必要です。
- 失敗時の復帰先は回収前の位置です。そこが水中・車内・危険な場所だった場合も安全な場所への移動は保証しません。
- 処理の詳細、自動テストと実機確認項目は [dev/DEVELOPMENT.md](dev/DEVELOPMENT.md) を参照してください。
