# Mediora Billing v0.1
Medical charge calculation and **draft-only** database records. Use /mbilldraft near another player. Server checks job/duty/distance/bucket, whitelisted prices and stores itemized draft invoices to oxmysql. Install install.sql first. Requires qbx_core, ox_lib and oxmysql.
No issue/send, debt, balance withdrawal, or okokBilling integration is implemented. Price defaults are provisional. Do not use drafts as evidence that treatment occurred; clinical linkage must later use server-verified treatment records. This version has not been tested in FiveM.
