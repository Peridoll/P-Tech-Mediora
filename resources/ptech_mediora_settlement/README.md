# Mediora Settlement v0.1
Standalone receipt review queue prototype, **not** an actual payout system.
Command: /msettle. Needs qbx_core, ox_lib, ox_inventory, oxmysql and install.sql.
No money transfer or receipt consumption occurs. Existing procurement receipt metadata must be audited before use. A server-side issuance ledger and idempotent money transfer are required for secure payout. FiveM tests not performed.
